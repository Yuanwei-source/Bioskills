# 信号 → 判定映射表

| 信号 | 初步判定 | 下一步 |
|------|----------|--------|
| 组装序列含模糊碱基 | 可能是后处理伪影或真实异质性 | 用 reads 碱基支持率区分 |
| 参考相似度低 | 可能是参考物种不合适 | 用小片段 COI 鉴定并更换参考 |
| 连续反向或断裂比对块 | 可能是组装错接 | 检查 reads 接缝和覆盖度 |
| 连接区持续低覆盖 | 可疑结构信号 | 检查 mate 位置和 soft-clip |
| 控制区低覆盖但有大量 clip | 可能是正常长度异质性 | 结合近缘参考和拷贝分布判断 |
| CDS 内部终止 | 可能是边界或读码框错误 | 用独立工具和蛋白比对定位 |
| 短基因或 tRNA 未命中 | 可能是工具灵敏度不足 | 用结构工具和参考全长锚定补充 |
