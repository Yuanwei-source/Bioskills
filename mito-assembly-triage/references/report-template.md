# 线粒体组装与注释结果报告模板

本报告面向需要决定“结果能否用于我的研究、哪些部分可信、接下来最值得做什么”的生物学使用者。正文先给出结果和用途判断，再呈现支持判断的组装、注释及 reads 证据。日志、完整命令、软件原始输出和大体积比对文件保存在 `intermediate/`，不在正文逐项抄录。

没有开展的检查保留栏目并写明“未评估”及其影响；证据不足写“未解决”，不得留空、写成通过或阴性结果。仅填写与该样本有关的内容，但固定章节顺序保持不变。

## 证据状态用语

- `SUPPORTED`：证据支持报告中明确写出的命题。
- `SUPPORTED_WITH_CAVEATS`：证据提供支持，但有影响适用范围或解释的限制。
- `UNRESOLVED`：证据冲突、歧义或不足以区分竞争解释。
- `NOT_ASSESSED`：本次没有执行该检查，不代表阴性结果。

对不同层级的命题分别判定，例如“序列与现有 reads 相容”与“物理闭环未验证”可以同时成立。观察、推断和操作分开写；“未发现”不等于“已排除”。

## 报告质量规则

- 不以 N50、基因数量、BUSCO、单个工具结果或 `circular` 标签独自判断线粒体组装正确。BUSCO 衡量指定保守单拷贝直系同源基因集的完整性，不直接验证线粒体碱基、连接或拓扑。
- 不把注释器预测升级为已确认的样本基因，不以近缘参考填补没有样本证据支持的碱基。
- 有用的报告应让读者在首页找到交付序列概况、注释概况、主要处理、最重要限制及用途建议；长日志和逐条程序输出留在 `intermediate/`。
- 输入、交付文件和分析所用参考应可追溯；报告引用参考时写数据库登录号及版本，不只写物种名。

## 参考依据

- [NCBI: Submitting Mitochondrial and Chloroplast Genomes to GenBank](https://www.ncbi.nlm.nih.gov/genbank/organelle_submit/)：线粒体提交准备、feature table 与注释合理性检查。
- [NCBI: Submission of annotation using a feature table](https://www.ncbi.nlm.nih.gov/genbank/feature_table/)：受控 feature/qualifier 与坐标格式。
- [QUAST 原始论文](https://pmc.ncbi.nlm.nih.gov/articles/3624806/)：组装质量需多指标审视，连续性统计可能掩盖误组装。
- [BUSCO 用户指南](https://busco.ezlab.org/busco_userguide)：完整性指标的对象是预期保守直系同源基因集；它不单独验证单个线粒体分子的组装真实性。
