# 诊断决策：分流、优先级与停止

证据门槛见 [evidence-standard.md](evidence-standard.md)，详细循环见
[diagnostic-playbook.md](diagnostic-playbook.md)。分流是可被新证据修正的工作假设。

## 1. 组装问题与注释问题

| 观测组合 | 优先检查 | 不能直接推出 |
|---|---|---|
| 基因区有连续 reads，同源支持连续，注释边界/读框异常 | 密码表、重译、边界、例外声明 | 连续覆盖不证明每个碱基都正确 |
| 局部零覆盖、split gene 落在断点或重复区 | 比对可解析性、contig/GFA、缺口与接缝 | 零覆盖不独自证明组装错误 |
| 局部深度超额 | 重复标记、竞争比对、混样/多倍型等解释 | 不直接判多拷贝或 NUMT |
| 末端大量 soft-clip 且低覆盖 | 端部重复、表示方式、错接与长度异质性 | 不直接判正常或不相接 |
| 两条路线仍都可能 | 选择能区分二者的检查；数据不足则保留未解决 | 不为收尾强行选一条 |

注释工具不能验证结构真实性；重组装不能替代密码表与注释边界检查。
判断真实缺失前，先排查漏注释、命名、跨原点坐标与检索灵敏度。

## 2. 优先级

| 层 | 适用检查 | 启用时机 |
|---|---|---|
| P0 结构真实性 | 接缝、覆盖异常、重复与来源 | 怀疑结构问题，或目标依赖结构真实性时优先 |
| P1 注释一致性 | 基因身份、边界、翻译、RNA 结构与顺序 | 可先做纯注释诊断，单独说明结构验证状态 |
| P2 生物学解释 | 真实丢失、重排、来源与类群解释 | 对相关技术和注释替代解释有充分排查之后 |

这是检查选择原则，不要求每个任务先完成全部 P0。选择下一项检查时说明它能改变哪条
假设、结论或修复验收；无关检查不运行。证据门槛由证据标准定义。

## 3. 停止条件

| 停止类型 | 条件 | 输出 |
|---|---|---|
| Stop A：关键输入缺失 | 缺少该命题必需的 reads、参考或其他输入 | 该命题未解决；无法评估时用 `not_assessable`，按证据标准 §2.1 限制，无关结论继续 |
| Stop B：没有有效下一项检查 | 已满足验收，或后续同类检查不会改变判断 | 列出结论、限制与停止理由；未解决事项仍保留 |
| Stop C：无法判别 | 当前数据不能区分竞争解释 | `UNRESOLVED`，指出最少需要的数据或实验 |
| Stop D：阴性功效不足 | 覆盖、读长或工具灵敏度不足以使阴性结果有判别力 | 记录弱阴性；若无可行补充则停止，不推出不存在 |

低覆盖阈值是工程提示，阴性功效须结合文库与局部可比对性判断。
没有读完所有参考文件、没有跑完所有工具，不构成继续的理由。

## 4. 科学判定、复核与权限

三者分别记录，避免把“待审核”混成“证据不足”。

| 维度 | 规则 | 记录位置 |
|---|---|---|
| 科学状态 | 按 claim 的证据给 `RESOLVED/NO_CHANGE/UNRESOLVED` 与置信度 | `anomalies[]`；案例级 decision 仅汇总 |
| 复核级别 | `AUTO` 常规自动检查；`ASSIST` 边界/身份等需要解释的检查；`EXPERT` 丢失、重排、环化、来源等重要解释 | 事件 result 与报告文字，当前无专用 CLI 字段 |
| 复核状态 | 未请求、待复核、已复核或有分歧，并附实际证据/审核记录 | 事件与报告 |
| 判定人与复核人 | 实际执行者姓名或代理标识；未审阅时不得填“人工已确认” | 与级别分开记录 |
| 采纳/发布权限 | 依据用户对具体动作的授权；科学结论不自动授权上传、发布或覆盖原件 | 任务授权记录 |

AI 可在授权任务内选参考、检查、整理证据与生成候选，无需为每条可逆分析等待确认。
重要解释建议专家复核；证据已满足标准而仅待复核时，不因未签字自动改为
`UNRESOLVED`，但必须显式写“待专家复核”。如果分歧揭示了尚未排除的重要解释，
则按实际证据调整状态与置信度。人工确认不能替代缺少的样本证据。
若用户明确要求人工签核后才采纳某项修改，执行动作应等待签核。

## 5. 参考选择

先确定需要支持的命题，再按参考的质量、类群与用途选择。
**等级和允许用途的唯一定义见 [reference-policy.md](reference-policy.md) §5**；
登记成功不代表参考可靠，也不意味着已有充分科学证据。

### 5.1 获取与登记

优先复用适用且版本已知的本地参考；需要新取时下载公共记录并登记。
用于注释比较的 GB 必须含所需注释；FASTA 可用于相应序列检索。
实际获取、版本固定和任务内登记方法见参考政策 §3–§4，不在此重复定义。
内建昆虫 ORDER 只用于测试与背景提示，不能代替样本适用参考。

## 6. 最小证据的入口

最低证据集中在 [evidence-standard.md](evidence-standard.md) §1。
选择检查前先区分目标：注释自洽、基因身份、样本碱基真实性、结构连接或生物学解释。
完整性若涉及样本结构，应按结构门槛验证；不能仅凭“37 个基因 + 有覆盖”确认完整。
tRNA 的未检出/候选丢失/无法解析分级见
[annotation_quality.md](annotation_quality.md) §3.1。
