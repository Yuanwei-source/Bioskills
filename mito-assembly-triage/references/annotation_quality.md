# 注释质量标准

> **适用边界**：优先面向典型后生动物（尤其昆虫）线粒体的**已有组装/注释复核**。其他类群必须先加载类群资料，
> 不得把本文件的默认基因集当成全类群通则。
> **执行者**：`scripts/annot_check.py`（本文标注"代码"的条目即由它执行）。证据要求见 `evidence-standard.md`。

## 0. 前置：先固定语境

判断任何"异常"之前，先确定并记录。缺少语境时先补语境，不要直接下结论。

| 项目 | 为什么必须 | 记录位置 |
|---|---|---|
| 类群（目/科，尽量到属） | 基因集、密码表、tRNA 结构、基因排列都可能类群特异 | `case.json` → `taxon` |
| 遗传密码表 `transl_table` | 后生动物线粒体多用 5；用错表会造出**假内部终止** | 命令参数 + 事件记录 |
| 组装状态 | 完整环 / 部分 / 多 contig；决定"缺失"是注释问题还是序列问题 | `case.json` → `inputs` |
| 注释来源与版本 | MITOS2 / MitoFinder / 手工；误差方向不同 | 事件 `tool_version` |

典型后生动物的预期基因集为 **13 CDS + 22 tRNA + 2 rRNA = 37**。
**缺失、重复与排列差异先记为待核查，不直接判定为"序列错误"**；不符合预期的类群须查类群文献与可信参考后判定，
并把特例证据写入案例。代码提供 `--allow-atypical` 把基因集差异从 ERROR 降级为待核查 WARN，
它是"要求逐项确认"的开关，**不是免责开关**。

## 1. CDS

1. 用类群确认的 `transl_table` **重译**每条 CDS，核对链方向、跨环（跨原点）起止坐标与阅读框。
2. 逐条记录：内部终止数、起始密码子、终止密码子（完整 / 不完整 `T`/`TA`）、同源蛋白覆盖度、边界证据。
3. **内部终止必须解释**。修复前按顺序排查：密码表选错 → 边界/阅读框错误 → 碱基错误（测序或组装）→ 真实生物学例外
   （假基因、RNA 编辑等）。不允许只修改结论文字而不解释成因。
4. 不完整终止（`T`/`TA`）与转录后多聚腺苷酸化可相容；**没有转录证据时不得宣称已实验验证**。
   代码：有 `note` 说明 → WARN；无 `note` → ERROR。
5. `cox1` 的 5' 起始边界特别易错（历史上多次出现被截短或被延长），单独谨慎判断。
6. 边界或序列修改必须能回答：**这个碱基是样本 reads 支持的，还是从参考"借"来的**（见 `evidence-standard.md`）。

## 2. tRNA

1. 统一命名（`trnX`），同时保留反密码子、位置、链方向、结构工具分数、同源性与相邻基因信息。
   CDS 侧的常见同义写法（`nad*`/`nd*`、`cob`/`cytb`、`coi`/`cox1`）由 `annot_check.py` 归一，**不应当作"非标准基因身份"**。
2. **必须区分两个 `trnL` 与两个 `trnS`**：`trnL1(CUN)` / `trnL2(UUR)`、`trnS1(AGN)` / `trnS2(UCN)`。
   命名退化（都写成 `trnL`/`trnS`）会造成**假重复 + 假缺失**，代码的基因身份检查会把 `trnL`→`trnL1`、`trnS`→`trnS1` 归一，
   但仍需人工确认反密码子。
3. 部分动物线粒体 tRNA 天然结构不完整（如某些 `trnS1` 缺 DHU 臂）。
   **不能仅凭三叶草结构不完整就判为假基因**；需结构 + 同源 + 邻域一致支持。
4. 代码的长度规则：`< 50 bp` 且无 `note` → ERROR；`< 50 bp` 且有 `note` → WARN；`60–75 bp` 之外 → WARN。
   长度只触发检查，不是身份判据。
5. 结构与同源证据冲突时保留 `UNRESOLVED`，不强行二选一。

## 3. rRNA

1. 名称映射：**12S → `rrnS`；16S → `rrnL`**（代码 `canonical_gene()` 已归一 `12S/16S/srrna/lrrna`）。
2. 用同源保守区、相邻基因和类群背景估计边界；长度差异只**触发检查**，
   **不把近缘参考的边界当真值**。
3. 代码范围：`rrnL` 1100–1500 bp、`rrnS` 600–850 bp，超出 → WARN（不是 ERROR）。

## 4. 基因重叠

1. 在规范化坐标（含环状跨原点）上报告每一对重叠：基因对、重叠 bp、链向、涉及边界。
   按 `CDS-CDS` / `CDS-tRNA` / `tRNA-tRNA` / 含 rRNA 分类解释，不要用一个总数概括。
2. 默认分级（`> 8 bp` 才报告，≤ 8 bp 不报告）：

   | 类型 | 默认等级 | 放宽方式 |
   |---|---|---|
   | `CDS-tRNA` | **ERROR** | `--tolerate-overlap "基因1,基因2"`（该对单独降为 ACCEPT）；或 `--overlap-severity warn`（全局降为待核查） |
   | 其他（含 `CDS-CDS`） | WARN | 无需开关，人工确认 |

3. `atp8-atp6`、`nad4-nad4l` 的短重叠是典型真实特征：**检查它，不强制消除它**。
4. **任何重叠都不构成"自动裁剪序列"的理由**。裁剪前必须有 reads 或独立结构证据。

## 5. 评分不跨越证据边界

"注释内部一致、基因身份可信、边界正确" 与 "原始 reads 支持该序列" 是**两个独立结论**，必须分别报告。
所有自动注释结果（**包括近缘参考自身的注释**）都可质疑。

## 6. 工具对照：`scripts/annot_check.py`

| 检查项 | 触发条件 | 默认等级 |
|---|---|---|
| 环状拓扑 | `--require-circular` 且 topology ≠ circular | ERROR |
| 基因数量 | CDS≠13 / tRNA≠22 / rRNA≠2 | ERROR（`--allow-atypical` → WARN） |
| 基因身份 | 缺失 / 非标准名 / 重复（`nad*`↔`nd*`、`cob`↔`cytb`、`coi/coii/coiii`↔`cox1/2/3`、`12S/16S`↔`rrnS/rrnL`、`trnL/trnS`→`trnL1/trnS1` 已归一） | ERROR（`--allow-atypical` → WARN） |
| 起始密码子 | 不在该密码表的合法起始集 | ERROR |
| 内部终止 | 翻译含内部 `*` | ERROR |
| 不完整终止 | 末 3 bp 非合法终止；无 `note` | ERROR（有 `note` → WARN） |
| tRNA 长度 | `<50`（无 `note`）/ 60–75 之外 | ERROR / WARN |
| 反密码子 | 缺 `anticodon` qualifier | WARN |
| rRNA 长度 | 超出类群范围 | WARN |
| 重叠 | `> 8 bp` | 见 §4 |
| 链分布 | 正链 CDS ≠ 9（昆虫标准） | WARN |
| 基因顺序（需 `--ref`） | 与参考 CDS 顺序不同 | WARN（顺序差异是 REVIEW 项，不是自动失败） |
| CDS 长度（需 `--ref`） | 与参考差 > 20% | WARN |

退出码：`0` 全通过；`1` 有错误；`2` 仅有警告但无错误。
