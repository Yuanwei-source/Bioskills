# 独立审查报告归档

本目录保存**审查方撰写**的独立审查报告，作为合并决策的审计记录。

## 收录规则

1. 只收录审查方（独立于实现方）产出的报告原文，**不做改写或删减**；如需说明请另开文件。
   **唯一例外：本地绝对路径在归档时会改为占位符**（如 `<repo-root>`）—— 公共仓库不放绝对路径；
   除此之外正文逐字保留，不因审查结论或措辞而修改。
2. 报告必须自带基线信息：`BASE` / `HEAD` SHA、测试环境与结果，以及哪些结论是实跑复现、哪些只是源码推断。
3. 与之配套的完整 patch **不入库**：`references-review/`（被 `.gitignore` 排除）保存本地的
   `PR1-FULL-DIFF.patch` / `PR2-FULL-DIFF.patch` 等中间产物，避免审查材料混入产品代码历史。
4. 报告中的结论只对其写明的 SHA 生效；后续提交不自动继承该结论。
